# Каталог серіалів

Веб-застосунок для пошуку серіалів і перегляду інформації про них: опис, рейтинг, жанри, акторський склад, епізоди за сезонами. Є особисті списки («Улюблене», «Хочу подивитись», «Переглянуто») та світла/темна теми.

- **Сайт:** https://tvcatalog.vercel.app/
- **Репозиторій:** https://github.com/khrystyna-saveliuk/tv-catalog-final

Індивідуальне завдання з веб-розробки. Бекенду, авторизації та бази даних немає: усі дані надходять із зовнішнього REST API, а особисті списки зберігаються в браузері.

## API

Використовується відкритий [TVmaze API](https://www.tvmaze.com/api), ключ не потрібен. Базова адреса: `https://api.tvmaze.com`, нижче наведено шляхи, що додаються до неї.

| Запит                     | Для чого                    |
| ------------------------- | --------------------------- |
| `GET /shows?page=0`       | список серіалів на головній |
| `GET /search/shows?q=...` | пошук за назвою             |
| `GET /shows/:id`          | деталі серіалу              |
| `GET /shows/:id/cast`     | акторський склад            |
| `GET /shows/:id/episodes` | епізоди                     |

Усі запити йдуть через одну функцію `request<T>` у `src/api/tvmaze.ts`. Вона обробляє помилку мережі, `404` та `429` (забагато запитів) і кидає власний `ApiError` з текстом, придатним для показу користувачу.

## Запуск

Потрібен Node.js 20.19+.

```bash
npm install        # встановити залежності
npm run dev        # сервер розробки, http://localhost:5173
npm run build      # перевірка типів + production-збірка у dist/
npm run preview    # локальний перегляд зібраної версії
```

## Перевірка якості

```bash
npm test              # 81 модульний тест
npm run lint          # ESLint
npm run format:check  # Prettier
npx tsc --noEmit      # перевірка типів
```

Тести покривають чисту логіку (фільтри, сортування, групування епізодів, розбір `?id=`, бібліотека, тема, очищення HTML), API-клієнт із підміненим `fetch` (успіх, `404`, `429`, мережева помилка) та DOM-компоненти (картка серіалу, стани завантаження й помилки, безпечна вставка тексту).

## Сторінки та функціонал

Застосунок складається з трьох HTML-сторінок (MPA), кожна має власний вхідний скрипт.

1. **Головна (`index.html`)**
    - пошук за назвою (за натисненням кнопки або Enter);
    - фільтри за жанрами (серіал має містити всі вибрані) і за десятиліттями (будь-яке з вибраних);
    - сортування, скидання фільтрів;
    - по 24 серіали, кнопка «Показати ще»;
    - при поверненні кнопкою «Назад» стан списку (пошук, фільтри, сортування, кількість показаних) відновлюється через `history.state`.
2. **Сторінка серіалу (`show.html?id=…`)**
    - опис, рейтинг, жанри, дати, постер;
    - акторський склад (перші 6, кнопка «Показати всіх / Сховати»);
    - епізоди з вибором сезону;
    - кнопки «Хочу подивитись», «Переглянуто» та «Улюблене» (улюбленим можна зробити лише переглянутий серіал).
3. **Бібліотека (`library.html`)**
    - три незалежні списки з окремою пагінацією;
    - тексти для порожніх списків.

Також: перемикач світлої/темної теми (враховує системну тему, запам'ятовується), стани завантаження та помилки з кнопкою «Спробувати ще раз» для кожного блоку даних окремо.

## Структура проєкту

```
src/
  api/          запити до TVmaze
  components/   елементи інтерфейсу
  pages/        скрипти сторінок
  utils/        допоміжна логіка
  styles/       CSS
tests/          тести
```

Логіка без DOM (`utils/`) відокремлена від відображення (`components/`, `pages/`), тому її легко тестувати без браузера.

## Ключові рішення

- **Три окремі сторінки.** Завдання передбачає простий багатосторінковий застосунок (MPA), де кожна сторінка — окремий HTML-файл; посилання на серіал (`show.html?id=…`) можна відкрити напряму й поділитися ним.
- **Дизайн-токени.** Кольори, відступи, радіуси й розміри тексту визначені змінними в `tokens.css` (базові та семантичні). Темна тема перевизначає лише семантичні змінні через `[data-theme='dark']`. Тема встановлюється маленьким скриптом у `<head>` до першого малювання, щоб не було блимання.
- **Безпека.** Вміст API вставляється через `textContent`, а HTML-опис серіалу перетворюється на текстові абзаци через `DOMParser`, без `innerHTML`.
- **Стійкість до збоїв.** `localStorage` викликається в `try/catch`, дані з нього перевіряються type guard-ом. Якщо сховище недоступне, користувач бачить пояснення, а застосунок працює далі.
- **Продуктивність.** Постери беруться розміром `medium` із явними `width`/`height` (без зсувів макета); перші картки завантажуються одразу, решта ліниво; CSS підключається через `<link>` у `<head>`.

## Доступність і SEO

- семантична розмітка: `header`, `nav`, `main`, `section`, `article`, `footer`, одна `h1` на сторінку, логічна ієрархія заголовків;
- посилання «Перейти до основного вмісту», `aria-current` у навігації;
- повідомлення про стан (`role="status"`) для завантаження, помилок і результатів;
- `aria-label` та `aria-pressed` для кнопок без тексту та перемикачів, декоративні іконки приховані від скрінрідерів;
- видимий `:focus-visible`, керування з клавіатури;
- контраст кольорів відповідає рівню AA за WCAG 2.2;
- враховуються системні налаштування: зменшення анімацій і темна тема;
- унікальні `title` і `meta description` на кожній сторінці.

## Обмеження

- Головна показує першу сторінку каталогу TVmaze (до 250 серіалів). Фільтри й сортування застосовуються до вже завантаженого набору, а пошук звертається до API й шукає по всій базі.
- Бібліотека зберігається в `localStorage` цього браузера: вона не синхронізується між пристроями й зникає після очищення даних сайту.
- Дані та зображення належать TVmaze; застосунок залежить від доступності їхнього API.
